# Kodz — identidade visual

Plataforma oficial: https://kodz.dev

[Ver identidade e personagens](https://kodz-identidade.talkmaker.chatgpt.site/kodz/)

[Baixar kit completo v3.0.0](https://github.com/mmpavao/kodz-brand-kit/releases/download/v3.0.0/kodz-identidade-completa.zip)

## Conteúdo

Logo oficial e suas variações, guia da marca, galeria responsiva, 12 personagens Kodz, 12 estados por personagem, SVGs animados, GIFs, WebPs e PNGs transparentes.

Inclui a biblioteca `code/kodz.js`, `window.KodzVisual`, componente React `code/Kodz.tsx`, tipos TypeScript, inventário e relatório de auditoria.

A distribuição v3.0.0 padroniza os textos, nomes de arquivos, funções, classes e metadados como Kodz. Foram verificadas as 144 combinações de personagem e estado, a biblioteca global e o componente React. Versões anteriores são registros históricos; use a versão atual.
